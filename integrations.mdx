## GitHub Integration

Connect your documentation to GitHub for version-controlled, collaborative content management.

<Steps>
  <Step title="Install GitHub App" icon="download">
    Install The Library Company GitHub App from the GitHub Marketplace.
  </Step>
  <Step title="Authorize Repository" icon="check-circle">
    Grant access to your documentation repositories.
    
    ````bash
git clone https://github.com/your-org/docs-repo.git
cd docs-repo
npm install
    ````
  </Step>
  <Step title="Configure Webhooks" icon="settings">
    Set up webhooks for automatic documentation updates.
    
    <ParamField body="repository" param-type="string" required="true">
      GitHub repository in format 'owner/repo'.
    </ParamField>
    
    <ParamField body="branch" param-type="string" required="false">
      Branch to sync with (default: main).
    </ParamField>
  </Step>
</Steps>

<Callout kind="tip">Use GitHub Actions to automate documentation publishing on every push.</Callout>

const linkToJira = async (docId, issueKey) => {
  const response = await fetch(`/api/docs/${docId}/jira`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({
      issueKey: issueKey,
      linkType: 'relates to'

## API Integrations

Build custom integrations using our REST API and webhooks.

<CodeGroup tabs="Node.js,Python">
  ````javascript
  // Node.js webhook handler
const express = require('express');
const app = express();

app.post('/webhook/docs', (req, res) => {
  const { event, data } = req.body;
  
  switch (event) {
    case 'doc.created':
      console.log(`New doc created: ${data.title}`);
      break;
    case 'doc.updated':
      console.log(`Doc updated: ${data.title}`);
      break;
  }
  
  res.sendStatus(200);
});

app.listen(3000);
  ````
  ````python
from flask import Flask, request

app = Flask(__name__)

@app.route('/webhook/docs', methods=['POST'])
def handle_webhook():
    data = request.get_json()
    event = data.get('event')
    
    if event == 'doc.created':
        print(f"New doc created: {data['title']}")
    elif event == 'doc.updated':
        print(f"Doc updated: {data['title']}")
    
    return '', 200

if __name__ == '__main__':
    app.run(port=3000)
  ````
</CodeGroup>
