## Authentication Methods

The Library Company supports multiple authentication methods to ensure secure access to your documentation resources. Choose the method that best fits your application's needs and security requirements.

<Tabs>
  <Tab title="API Keys" icon="key">
    Use API keys for programmatic access to our platform.
    
    <Steps>
      <Step title="Generate API Key" icon="plus">
        Log into your dashboard and navigate to the API Keys section.
        
        ````bash
        curl -X POST https://api.librarycompany.com/v1/keys \
          -H "Authorization: Bearer YOUR_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{"name": "My App Key", "permissions": ["read", "write"]}'
        ````
      </Step>
      <Step title="Configure Headers" icon="settings">
        Include the API key in your request headers.
        
        <ParamField header="X-API-Key" param-type="string" required="true">
          Your generated API key for authentication.
        </ParamField>
      </Step>
    </Steps>
    
    <Callout kind="danger">Keep your API keys secure and never expose them in client-side code.</Callout>
  </Tab>
  <Tab title="OAuth 2.0" icon="lock">
    Implement OAuth 2.0 for user-based authentication and authorization.
    
    <CodeGroup tabs="JavaScript,Python">
      ````javascript
      // OAuth 2.0 client setup
const oauthClient = {
  clientId: 'your-client-id',
  redirectUri: 'https://yourapp.com/callback',
  scope: 'docs.read docs.write'
};
      ````
      ````python
from oauthlib.oauth2 import WebApplicationClient

client = WebApplicationClient(client_id='your-client-id')
      ````
    </CodeGroup>
  </Tab>
  <Tab title="JWT Tokens" icon="shield">
    Use JSON Web Tokens for stateless authentication.
    
    <Expandable title="Token Structure" default-open="false">
      JWT tokens consist of three parts: header, payload, and signature.
      
      ````json
      {
        "header": {
          "alg": "HS256",
          "typ": "JWT"
        },
        "payload": {
          "sub": "user123",
          "exp": 1638360000,
          "permissions": ["docs:read", "docs:write"]
        },
        "signature": "base64-encoded-signature"
      }
      ````
    </Expandable>
  </Tab>
</Tabs>

## Security Best Practices

Implement these security measures to protect your authentication credentials and maintain secure access to our platform.

<Steps>
  <Step title="Use HTTPS" icon="lock">
    Always use HTTPS for all API requests to encrypt data in transit.
  </Step>
  <Step title="Rotate Keys Regularly" icon="refresh-cw">
    Regularly rotate your API keys and tokens to minimize security risks.
    
    <Callout kind="tip">Set up automated key rotation using our management API.</Callout>
  </Step>
  <Step title="Implement Rate Limiting" icon="clock">
    Use rate limiting to prevent abuse and ensure fair usage.
    
    <ParamField query="limit" param-type="integer" required="false">
      Maximum number of requests per minute (default: 100).
    </ParamField>
  </Step>
</Steps>

## Integration Examples

See how authentication works in real-world scenarios.

<CodeGroup tabs="Node.js,Python,Go">
  ````javascript
  // Node.js authentication example
const authenticate = async (apiKey) => {
  try {
    const response = await fetch('https://api.librarycompany.com/v1/docs', {
      headers: {
        'X-API-Key': apiKey,
        'Content-Type': 'application/json'
      }
    });
    if (response.ok) {
      return await response.json();
    } else {
      throw new Error(`Authentication failed: ${response.status}`);
    }
  } catch (error) {
    console.error('Authentication error:', error);
  }
};
  ````
  ````python
import requests

def authenticate(api_key):
    headers = {
        'X-API-Key': api_key,
        'Content-Type': 'application/json'
    }
    response = requests.get('https://api.librarycompany.com/v1/docs', headers=headers)
    if response.status_code == 200:
        return response.json()
    else:
        raise Exception(f'Authentication failed: {response.status_code}')
  ````
  ````go
package main

import (
    "fmt"
    "io/ioutil"
    "net/http"
)

func authenticate(apiKey string) ([]byte, error) {
    client := &http.Client{}
    req, err := http.NewRequest("GET", "https://api.librarycompany.com/v1/docs", nil)
    if err != nil {
        return nil, err
    }
    req.Header.Set("X-API-Key", apiKey)
    req.Header.Set("Content-Type", "application/json")
    
    resp, err := client.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    
    if resp.StatusCode != 200 {
        return nil, fmt.Errorf("authentication failed: %d", resp.StatusCode)
    }
    
    return ioutil.ReadAll(resp.Body)
}
  ````
